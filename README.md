# Painel simulado do Protocolo de Governança das Compras Sustentáveis

Protótipo didático interativo elaborado para o trabalho do Grupo 1 sobre compras públicas sustentáveis no STJ.

## Conteúdo

- painel com 329 registros simulados;
- comparação entre o PCS oficial e a aderência no universo elegível;
- filtros por trimestre, unidade e classificação;
- apresentação guiada em 11 etapas;
- cronograma de implantação do protocolo;
- trilha simulada de evidências.

## Aviso

Todos os dados são fictícios e não representam a base oficial do Superior Tribunal de Justiça.
